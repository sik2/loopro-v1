# 07: `Published` 공개 범위

**What to build:** `Member`가 글을 발행하지 않은 상태로 저장할 수 있다. 발행하지 않은 `Post`는 목록에도 상세에도 남에게 보이지 않고, 작성자 본인만 본다. 나중에 발행할 수도, 발행한 글을 도로 내릴 수도 있다.

`Published`는 이 플랫폼의 **유일한** 공개 범위 개념이다. 지정 공유나 링크 공유는 없다.

**Blocked by:** 06 (`Post` 수정·삭제와 권한), 09 (`Comment`)

**Status:** done

- [x] `Post`에 `Published` 상태가 생긴다
- [x] 작성할 때 발행 여부를 고를 수 있다
- [x] 수정으로 발행/비발행을 전환할 수 있다
- [x] 발행되지 않은 `Post`는 목록에서 작성자 본인에게만 보인다
- [x] 발행되지 않은 `Post`의 상세는 작성자 본인만 볼 수 있다. 남에게는 404다 — 403이면 글의 존재가 드러난다
- [x] 발행되지 않은 `Post`에는 작성자 본인이 아니면 `Comment`를 달 수 없다
- [x] 걸러내기는 서비스 계층에서 한다
