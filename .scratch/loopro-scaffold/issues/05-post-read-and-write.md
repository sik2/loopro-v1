# 05: `Post` 목록·상세·작성

**What to build:** `Member`가 마크다운으로 글을 쓴다. 방문자는 로그인 없이 글 목록을 페이지 단위로 넘겨보고, 상세를 열어 렌더링된 본문을 읽는다. 이 티켓이 끝나면 플랫폼이 처음으로 "쓸 수 있는 것"이 된다.

ADR-0001에 따라 교안은 별도 엔티티가 아니라 긴 `Post`다. `Lesson`이나 `Material` 같은 것을 만들지 않는다.

**Blocked by:** 04 (로그인과 인증)

**Status:** done

- [x] `Post` 엔티티: 제목, 마크다운 본문, 작성자. 공통 상위 클래스를 상속한다
- [x] back은 마크다운을 해석하지 않는다. 텍스트로 저장하고 그대로 반환한다
- [x] 작성 API. 인증을 요구한다
- [x] 목록 API는 오프셋 페이징을 쓴다. 얇은 페이지 DTO로 감싸고 페이지 번호는 1부터다
- [x] 목록은 최신순 고정이다. 정렬 옵션은 없다
- [x] 목록 항목에 제목·작성자 `Nickname`·작성일이 담긴다
- [x] 상세 API. 존재하지 않는 `Post`는 404다

- [x] 렌더링 시 새니타이징한다. 사용자 입력을 HTML로 그리므로 필수다
- [x] 작성 화면에서 글을 쓰면 그 글의 상세로 이동한다
