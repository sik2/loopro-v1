# 02: front-react 부트스트랩

**What to build:** 개발자가 `front-react`의 개발 서버를 띄우면 빈 레이아웃이 브라우저에 뜬다. 스펙에 정의된 화면 경로들이 자리만 잡혀 있고 내용은 비어 있다. 이 티켓의 목적은 이후 화면 티켓들이 올라설 바닥을 놓는 것이다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Vite + React + TypeScript 프로젝트가 `front-react`에 구성된다. Next.js는 쓰지 않는다
- [x] 개발 서버가 뜨고 공통 레이아웃이 보인다
- [x] 클라이언트 사이드 라우팅이 설정되고, 다음 경로가 자리만 잡혀 있다: 글 목록, 글 상세(`/p/:id` 형태), 글 작성, 글 수정, 로그인, 회원가입, 내 정보
- [x] Tailwind 4가 Vite 플러그인으로 통합된다. **play CDN을 쓰지 않는다** — 브라우저에서 런타임에 CSS를 만드는 개발용 도구이기 때문이다
- [x] UI는 shadcn 방식(헤드리스 프리미티브 + 유틸리티 조합)을 쓴다. DaisyUI를 쓰지 않는다
- [x] Pretendard 다이나믹 서브셋 웹폰트가 적용된다
- [x] 서버 상태를 다루는 데이터 페칭 라이브러리가 설정된다
- [x] 폼 라이브러리와 스키마 검증 라이브러리가 설정된다
- [x] API 기본 주소가 환경변수로 주입된다. 코드에 하드코딩하지 않는다
- [x] 응답이 실패일 때 `ProblemDetail` 본문을 읽어 다룰 수 있는 공통 API 클라이언트가 있다
- [x] 타입 체크와 린트가 통과한다
