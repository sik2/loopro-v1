# 세션 대신 JWT를 쓴다

back은 REST API만 내고 화면은 `front-react`가 그린다. 로그인 상태는 세션 쿠키가 아니라 JWT access token으로 유지한다. 이유는 지금 코드에 드러나지 않는 곳에 있다 — `front-kmp`(모바일)가 나중에 같은 API를 쓸 예정이고, 그때 쿠키는 다루기 번거롭다. 지금 시점만 보면 세션 쿠키가 더 단순하므로, 이 선택은 미래 클라이언트를 위한 것이다.

## Consequences

- refresh token을 두지 않는다. access token 유효기간은 7일이다.
- **로그아웃해도 그 토큰은 만료 전까지 유효하다.** 서버는 토큰을 무효화할 수 없고, front가 저장된 토큰을 지우는 것이 로그아웃의 전부다. 토큰이 탈취되면 최대 7일간 위험 구간이 남는다.
- 이 문제를 해결하려면 refresh token 회전이나 블랙리스트가 필요하며, 그때 이 ADR을 다시 연다.
- CSRF 보호는 끈다. stateless라 필요 없다.
