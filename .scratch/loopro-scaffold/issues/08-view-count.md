# 08: `ViewCount`

**What to build:** `Post` 상세를 열 때마다 조회수가 오르고, 목록과 상세에 표시된다. 작성자가 반응을 가늠할 수 있게 된다.

`ViewCount`는 **고유 독자 수가 아니다.** 같은 사람이 새로고침하면 계속 오른다.

**Blocked by:** 05 (`Post` 목록·상세·작성)

**Status:** done

- [x] `Post`에 `ViewCount`가 생긴다
- [x] 상세 조회 요청마다 1 증가한다. 같은 사람의 반복 조회를 구분하지 않는다
- [x] 따라서 상세 조회가 쓰기 트랜잭션이 된다. 조회마다 UPDATE가 나간다는 사실을 알고 구현한다
- [x] 목록과 상세 응답에 `ViewCount`가 담긴다
- [x] 화면에 표시된다. 조작하는 수단은 없다
- [x] HTTP seam 테스트: 상세를 두 번 조회한 뒤 재조회하면 `ViewCount`가 그만큼 늘어 있다
