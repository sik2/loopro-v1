# 10: `PostLike`

**What to build:** `Member`가 글을 추천하고 취소한다. 이미 추천한 글을 다시 눌러도 중복으로 쌓이지 않는다. 화면의 추천 버튼이 내가 이미 추천했는지를 정확히 반영하고, 추천수는 누구에게나 보인다.

추천은 **값을 세는 counter가 아니라 누가 무엇을 추천했는지의 기록**이다.

**Blocked by:** 05 (`Post` 목록·상세·작성)

**Status:** ready-for-agent

- [ ] `PostLike` 엔티티: 추천한 `Member`와 대상 `Post`. 공통 상위 클래스를 상속한다
- [ ] `Post`와 `Member`의 조합에 유일 제약이 걸려 있다. DB가 중복을 막는다
- [ ] 추천 API와 취소 API. 인증을 요구한다
- [ ] 이미 추천한 대상을 다시 추천해도 기록이 늘지 않는다
- [ ] `Post` 목록·상세 응답에 추천수가 담긴다
- [ ] 요청이 인증된 경우 "내가 이 `Post`를 추천했는지"가 응답에 함께 담긴다
- [ ] 상세 화면의 추천 버튼이 내 추천 상태를 반영한다
- [ ] 로그인하지 않은 상태로 추천하려 하면 로그인하라고 안내한다
- [ ] HTTP seam 테스트: 추천 후 **재조회**로 추천수 증가와 "내가 추천함"을 확인 / 중복 추천이 쌓이지 않음 / 취소 후 **재조회**로 감소와 "추천 안 함"을 확인. 추천 API가 200을 냈다는 것만으로 통과시키지 않는다
