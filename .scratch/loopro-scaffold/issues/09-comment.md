# 09: `Comment`

**What to build:** 방문자가 `Post` 상세에서 달린 댓글을 전부 읽는다. `Member`는 댓글을 달고, 자기 댓글을 고치고 지운다. 남의 댓글은 손댈 수 없고, `ADMIN`은 지울 수 있다.

`Comment`에는 `Comment`를 달 수 없다. 대댓글은 없다.

**Blocked by:** 05 (`Post` 목록·상세·작성)

**Status:** done

- [x] `Comment` 엔티티: 내용, 작성자, 속한 `Post`. 공통 상위 클래스를 상속한다
- [x] `Comment`가 `Comment`를 가질 수 없는 구조다
- [x] 목록 API는 페이징 없이 전부 낸다. 대댓글이 없고 스캐폴딩 단계이므로 한 번에 내려도 된다
- [x] 작성·수정·삭제 API. 인증을 요구한다
- [x] 수정은 작성자 본인만, 삭제는 본인과 `ADMIN`이 할 수 있다
- [x] 권한 없는 요청은 403이다
- [x] 목록 항목에 작성자 `Nickname`과 작성일이 담긴다
- [x] `Post` 목록·상세 응답에 댓글수가 담긴다
- [x] 상세 화면 안에서 댓글을 보고 달고 고치고 지운다. 별도 화면을 만들지 않는다
- [x] 로그인하지 않은 상태로 댓글을 달려 하면 로그인하라고 안내한다
- [x] HTTP seam 테스트: 목록 조회 / 작성 / 수정 / 삭제 / 남의 댓글 수정 거부 / 남의 댓글 삭제 거부 / `ADMIN` 삭제 허용
