# 06: `Post` 수정·삭제와 권한

**What to build:** `Member`가 자기 글을 고치고 지운다. 남의 글은 손댈 수 없다. `ADMIN`은 문제되는 글을 지울 수 있지만 고칠 수는 없다 — 삭제는 관리 행위지만 수정은 위조이기 때문이다.

**Blocked by:** 05 (`Post` 목록·상세·작성)

**Status:** ready-for-agent

- [ ] 수정 API는 작성자 본인만 허용한다. `ADMIN`이라도 남의 글은 수정할 수 없다
- [ ] 삭제 API는 작성자 본인과 `ADMIN`이 할 수 있다
- [ ] 권한 없는 요청은 403이다
- [ ] 수정 화면에서 제목과 본문을 고칠 수 있다
- [ ] 상세 화면에서 수정·삭제 버튼이 권한 있는 사람에게만 보인다
- [ ] 삭제하면 목록으로 이동한다
- [ ] HTTP seam 테스트: 본인 수정 성공 / 남의 글 수정 거부 / `ADMIN`의 남의 글 수정도 거부 / 본인 삭제 성공 / 남의 글 삭제 거부 / `ADMIN`의 남의 글 삭제 허용
